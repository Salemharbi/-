# خادم المحامي الذكي

خادم وسيط بين تطبيق الجوال ونموذج Claude. يحتفظ بمفتاح Anthropic على الخادم فقط،
ولا يصل المفتاح إلى التطبيق أبداً.

## المسارات

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/health` | حالة الخادم، وهل الذكاء الاصطناعي مُعدّ. لا يحتاج رمزاً. |
| POST | `/legal/chat` | محادثة قانونية. الجسم: `{ "messages": [{ "role": "user"|"assistant", "content": "..." }] }` |
| POST | `/legal/analyze` | تحليل مستند. الجسم: `{ "text": "..." }` |

كل المسارات عدا `/health` تتطلب الترويسة `Authorization: Bearer <APP_API_TOKEN>`.

الرد على `/legal/chat`: `{ "reply": "...", "refused": false }`
الرد على `/legal/analyze`: `{ "summary": "...", "keyPoints": [...], "risks": [...], "refused": false }`

## الإعداد

```bash
cd server
cp .env.example .env   # ثم املأ القيم
npm install
npm test               # يبني المشروع ويشغّل الاختبارات (لا يحتاج مفتاحاً)
npm start
```

| المتغير | الإلزام | الوصف |
|---|---|---|
| `ANTHROPIC_API_KEY` | نعم للتشغيل الفعلي | مفتاح Anthropic. بدونه يعمل الخادم لكن يرد 503. |
| `APP_API_TOKEN` | نعم | رمز يتحقق منه الخادم، 16 حرفاً على الأقل. |
| `ANTHROPIC_MODEL` | لا | الافتراضي `claude-opus-5-5`. |
| `REFUSAL_FALLBACK` | لا | `default` (الافتراضي) أو `off`. |
| `RATE_LIMIT_PER_MINUTE` | لا | الافتراضي 30 طلباً لكل رمز وعنوان IP. |
| `PORT` | لا | الافتراضي 8787. |

## السلوك

- **النموذج**: `claude-opus-5-5` بالتفكير التكيفي الافتراضي. الجهد `medium` للمحادثة و`high` للتحليل.
- **الرفض والاحتياطي**: مفعّل افتراضياً عبر `fallbacks: "default"` وترويسة `server-side-fallback-2026-07-01`.
  عند رفض النموذج يعاد النموذج الاحتياطي تلقائياً، وإن رفض الكل يعاد نص اعتذار عام بدل المحتوى.
  للتعطيل: `REFUSAL_FALLBACK=off`.
- **تحليل المستندات**: يستخدم مخرجات مُهيكلة (`json_schema`) ثم يتحقق الخادم من الشكل قبل إرساله للتطبيق.
- **الحدود**: 1 MB للجسم، 40 رسالة، 8000 حرف لكل رسالة، 150000 حرف للمستند.
- **الأخطاء**: لا تُرسل تفاصيل داخلية للتطبيق. يُسجَّل نوع الخطأ فقط، ولا يُسجَّل محتوى الطلب أو المفتاح.

## ملاحظات أمنية

- رمز `APP_API_TOKEN` الذي يضعه التطبيق في الجوال **يمكن استخراجه من حزمة التطبيق**. هذا حل مؤقت للتطوير.
  قبل النشر للمستخدمين يلزم تسجيل دخول لكل مستخدم (رموز قصيرة العمر) بدلاً من رمز مشترك.
- حد الطلبات في الذاكرة، أي أنه يُعاد عند إعادة تشغيل الخادم، ولا يعمل عبر عدة نسخ. يُستبدل بحد مركزي عند التوسع.
- لا يحفظ الخادم أي محتوى للمحادثات أو المستندات.
