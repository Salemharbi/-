# المحامي الذكي (Smart Lawyer)

تطبيق جوال (Expo / React Native + Expo Router) يساعد العملاء والمحامين في:

1. **الاستشارات القانونية بالذكاء الاصطناعي**: محادثة تجيب عن الأسئلة القانونية العامة.
2. **صياغة المستندات والعقود**: قوالب جاهزة (عقد إيجار، عقد عمل، اتفاقية عدم إفشاء، توكيل، إنذار رسمي) تُملأ بالبيانات.
3. **تحليل المستندات**: تلخيص مستند نصي واستخراج النقاط المهمة والمخاطر.
4. **إدارة القضايا**: تسجيل القضايا وبيانات الموكّلين وأرقام القضايا والمحاكم.
5. **الجلسات والتغذية الراجعة**: جدولة الجلسات وتسجيل الحضور ونتيجة كل جلسة.

## التشغيل

```bash
cd app
npm install
npx expo start
```

الواجهة من اليمين إلى اليسار. إذا لم تظهر بالاتجاه الصحيح بعد أول تشغيل، أعد تشغيل التطبيق.

## الخادم الخلفي (للذكاء الاصطناعي)

التطبيق **لا يحتوي على أي مفتاح API**. يرسل الطلبات إلى خادم تملكه، والخادم يستدعي نموذج Claude ويحفظ المفتاح.
اضبط عنوان الخادم في ملف `.env`:

```bash
EXPO_PUBLIC_API_URL=https://api.example.com
```

الخادم مطلوب بنقاط نهاية JSON بطريقة POST:

| المسار | الإدخال | المخرج |
|---|---|---|
| `/legal/chat` | `{ messages: [{role, content}] }` | `{ reply: string }` |
| `/legal/analyze` | `{ text: string }` | `{ summary: string, keyPoints: string[], risks: string[] }` |

بدون هذا الخادم تعمل بقية الوظائف (القوالب، القضايا، الجلسات) بشكل كامل، وتظهر رسالة توضح أن الذكاء الاصطناعي غير مُعدّ.

## ملاحظات مهمة

- القوالب والإجابات **عامة** ولا تغني عن استشارة محامٍ مرخّص، ويجب مراجعتها قبل الاعتماد.
- البيانات محفوظة محلياً على جهاز المستخدم فقط (AsyncStorage). لا توجد مزامنة بين الأجهزة بعد.
- تحليل الملفات حالياً للنصوص (`.txt`) فقط. دعم PDF وWord يحتاج معالجة على الخادم.
